# Images

Ce chapitre exerce les deux gabarits d'image : une capture large, qui occupe toute la colonne, et une capture étroite.

## Image large

1. Déposez le fichier dans la zone d'envoi.

   ![Zone d'envoi fictive](images/capture-large.png)

   La zone affiche le nom du fichier.

2. Lisez le statut affiché.

## Image étroite

![Icône fictive](images/capture-petite.png)

Le paragraphe qui suit une image doit garder une distance régulière avec elle, quelle que soit la page où elle tombe.
