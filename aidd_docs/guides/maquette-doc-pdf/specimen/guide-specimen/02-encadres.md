# Encadrés et citations

Ce chapitre exerce chaque type d'encadré, le code et les renvois. Chaque encadré commence par son libellé en gras.

> **Bon à savoir** Une information utile, sans risque : elle complète le texte sans l'interrompre.

> **Attention** Un point de vigilance. Cet encadré porte deux paragraphes pour montrer la suite d'un même encadré.
>
> Le second paragraphe prolonge l'encadré qui le précède.

> **À retenir** L'essentiel du chapitre, en une ou deux phrases.

## Code et valeurs

Le champ `reference` accepte des lettres et des chiffres, par exemple `AB-1234`. Un nom de fichier long comme `documentation.config.json` doit rester lisible dans la colonne.

Une procédure suivie d'un encadré :

1. Préparez le fichier.
2. Envoyez-le.
3. Vérifiez le résultat.

> **Attention** L'envoi remplace le fichier existant.

## Notes de renvoi

> **Renvoi** Pour la mise en page des images, voir le chapitre suivant.

Un dernier paragraphe, après la note de renvoi, pour vérifier que la colonne marginale n'écrase pas le texte courant.
